### Fixed, flashed, awaiting a human's eyes

- **Randy N4OPI — screensaver tap acted where you touched.** FIXED. Root cause:
  `lv_indev_get_next(NULL)` returns the *most recently created* indev (LVGL inserts at the
  head), so sleep disabled the **mouse** and left **touch** live. Broken since v1.3.0 added
  the pointer indev. Now walks every indev and resets them on wake.
- **Randy N4OPI — web UI spots / frequency readout "nearly microscopic".** FIXED. Canvases
  are sized `clientWidth * dpr` and the context is never `ctx.scale()`d, so canvas units are
  DEVICE pixels: a literal `14px` renders about 7 CSS px at dpr 2. `drawSpots`,
  `drawSpotPreview` and `drawTuneCursor` now scale font **and** box geometry together.
- **Markus DL8MBY — #188, radio receiving on VFO B.** Fix verified running on hardware
  (`cat: VFO mode: receiving on VFO A, as this firmware assumes`). Only the benign path is
  proven; the *correcting* path (a radio genuinely on VFO B) is untested.
  Reply already written and unsent: `docs/reply-dl8mby-vfo.md`.

- **Roy KI0ER — tuning "dance" (+10 Hz, then +25 more, then back).** This is **spur

## 5. Traps this session paid for — do not re-pay them

- **Flashing resets the Tab5, which is the #74 trigger.** It fired on **3 of 3** resets in
  one day; the port retry rescued **2 of 3**, one stuck for 4 h 37 m. It is
  **probabilistic** — "it worked last time" is not a safe inference. The only reliable
  avoidance is the **radio being OFF during the flash**. Offer that before every flash.
- **`main/CMakeLists.txt` lists SRCS explicitly — it does not glob.** A new `main/util/*.c`
  must be added there or every reference is an undefined symbol at link, including from
  files in the same component.
- **Bash eats backslashes in Windows paths.** `-Out C:\dev\...` silently became one mangled
  relative filename. Quote the path and use forward slashes.
- **A normal diag-log rotation logs NOTHING** (only the ENOSPC path does), and
  `/api/log/saved` is a rolling ~25-minute window. Sampling it right after a rotation looks
  alarmingly small; check its LAST timestamp against uptime before concluding anything.
- **A concurrent session deleted a git worktree mid-investigation**, after which a relative
  ELF path silently resolved against the wrong build and produced confident nonsense. Use
  absolute paths for ELF files and re-check the worktree still exists.
- **Write documents with the Write tool, not a shell heredoc** — this file broke a heredoc
  twice before being written properly.
