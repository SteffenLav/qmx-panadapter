# M5Tab5-Keyboard-UserDemo

## Overview

### SKU: A164

Contains M5Stack **Tab5 Keyboard** series related case programs. Tab5 Keyboard is a 70-key physical keyboard input expansion module designed for Tab5, communicating via I2C (default address 0x6D, SDA=0, SCL=1, INT=50) with STM32F030C8T6 main control.
