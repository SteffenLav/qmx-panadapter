## 2. OTA is live, and it changes the release process permanently

⚠ **EVERY future release MUST attach the raw `qmx_panadapter.bin`.** The device
builds `.../releases/download/<tag>/qmx_panadapter.bin` from the tag. A release
without it makes every user's update attempt end at `Failed - tap retries`.
Written into `release_process` memory with the exact command; curl the real URL
before announcing.

⚠ **Docs must be finalised BEFORE the tag** — editing `docs/mkdocs/**`
regenerates `manual.bin`, and v1.8.8 shipped carrying v1.8.7's manual because
the docs pass came after. But `latest.json` takes its version from the newest
tag, so the order is: docs → PDF → tag → `mkdocs build` → commit → **move the
tag onto that commit** → clean firmware build. v1.8.9 did this correctly.

⭐ **v1.9.0 will be the first genuine end-to-end OTA test.** The `tap?` OFFER
state cannot appear until a release NEWER than the running build exists, so it
has only ever been proven by injecting it in a browser. When v1.9.0 is cut, the
bottom bar on a v1.8.9 device should go cyan by itself. That is the moment the
feature is actually confirmed.

## 5. Traps learned today, all now in CLAUDE.md or memory

- **A mistyped `/api/cmd` action is a SILENT no-op** — `unknown action`, HTTP
  200. It is `set_screen`, not `screen`. Twelve toggles "proved" #38's leak was
  gone; nothing had run, and I invented a mechanism to explain the flat result.
- **`sendCmd()` used to discard the response body**, so refusals were invisible.
  Fixed, but the lesson stands: check the BODY, never just the status.
- **Never send a backslash escape through a heredoc** — it collapsed `\n` into
  real newlines and `\0` into NUL bytes, twice, in one session. Build escapes
  from `chr(92)`.
- **Task stacks are tiny**: ~384 bytes of locals added to `status_task` (4 KB)
  crashed it twice. Statics, and the stack is now 8 KB.
- **A PSRAM stack cannot run with the cache disabled** — the OTA task panicked
  at 96 % because writing flash disables the cache. `psram_task.h` now forbids it
  for anything touching flash.
- **tab5.lav.dk's WAF returns HTTP 455 to generic user-agents.** The firmware's
  own `qmx-panadapter-tab5` gets 200. Do not diagnose a non-existent outage.
- **Measure with an antenna.** Spur suppression was characterised on an open BNC
  at 38.6 dB; with a real antenna it is 22.7 dB. The bench flattered it badly.
