## To BD4AHS (robot calling already-worked stations)

Hi,

That one is a setting, not a bug. The auto-answer picker only skips stations you
have already worked if **Exclude worked before** is ticked in the same Filter
window. With it unticked, every CQ is a valid target, including stations already in
your log. Tick it and the repeats stop.

The skip is per band, so the same station on another band is still fair game.

My own notes described that skip as automatic, which was wrong and is probably why
you expected it to work without the tick. I have corrected them.

Thanks also for confirming the transmit power reads correctly on 1.4.0.

73, Steffen OZ1LAV
