## Highlights  The panadapter now streams its spectrum and waterfall live to any browser on the LAN, with the same look and feel as the device screen.  ## What's new  ### Web UI shipped Phases 1-3 of the remote panadapter front-end land together: an HTTP status page on `/`, a polled `/api/status` JSON endpoint, and a binary `/ws` WebSocket streaming the live spectrum at ~10 fps. The browser canvas renders a continuous-curve spectrum and a full 512-row waterfall with auto-tracking noise floor.  ### Unified visual identity Tab5 device and browser share the same thermal waterfall palette (black to dark blue to teal to green to yellow to red), the same floor-tracking maths (median + 6 dB bias, 30 dB dynamic range above floor), and the same closed-polyline spectrum rendering. A signal of a given strength looks the same in both places.  ### Pixel-perfect screenshots The Phase 5.11 long-press screenshot infrastructure now reliably round-trips through `tools/screenshot_decode.py`. The headline image in the README is its own output.  ### ESP-DSP fallback to portable C FFT The ESP32-P4 PIE / vector FFT (`dsps_fft2r_fc32_arp4.S`) crashed deterministically under sustained WebSocket load; falling back to `CONFIG_DSP_ANSI=y` removed the failure mode at the cost of ~10% FPS (35-42 vs 40-45). To revisit once upstream esp-dsp PIE preemption handling matures.  ## Getting started  1. Flash the merged binary (`qmx_panadapter-v0.9.0-merged.bin`) directly from [web.esphome.io](https://web.esphome.io/) using Chrome or Edge 2. Configure WiFi via the on-screen credential modal in the settings drawer (introduced in v0.8.0) 3. Open the web UI at `http://<tab5-ip>/` - the Tab5''s IP is shown in the bottom status bar and in the boot log  ## Web API  - `GET /` - landing page with live spectrum + waterfall canvases and a status card - `GET /api/status` - JSON: battery level / charging, WiFi SSID / RSSI / IP, current VFO frequency - `GET /ws` - binary WebSocket; each 1026-byte frame is `[type=0x01][reserved=0][1024 x u8 quantised -130..-30 dBm]` at ~10 fps  See the [README](https://github.com/SteffenLav/qmx-panadapter/blob/main/README.md) for full details.  ## Known issues  - Settings stored in the default `nvs` partition may be wiped by merged-binary reflashes (fixed in v0.9.4)  ---  **Full changelog:** [v0.8.3...v0.9.0](https://github.com/SteffenLav/qmx-panadapter/compare/v0.8.3...v0.9.0)  73 de OZ1LAV
