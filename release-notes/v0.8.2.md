## Highlights  Real battery indicator in the bottom bar - the headline change since v0.8.1. Plus an important fix: charging was never being enabled in firmware, so the cell would slowly run down even with USB-C connected. v0.8.2 fixes both.  ## What's new  ### Battery charging now actually works The M5Stack Tab5 BSP defines `bsp_set_charge_en()` and `bsp_set_charge_qc_en()` but the previous firmware never called either. The cell would discharge over time and die immediately on USB-C unplug. v0.8.2 enables both at boot, including QuickCharge negotiation.  ### Real INA226 battery readout The bottom-bar percentage was a hardcoded stub in v0.8.1. Now it''s a real reading from the Tab5''s INA226 power monitor (I2C address 0x41 on the main bus):  - **Percentage** computed from a linear voltage-to-SoC curve for the 2S LiPo (6.6 V = 0%, 8.3 V = 100%) - **Charging indicator** (lightning bolt) appears when shunt current shows current flowing into the battery  Both update once per second. Small purpose-built driver (`main/util/ina226.c`) reads the chip directly over ESP-IDF v5''s `i2c_master` API - no calibration register dance, all math done in software.  ### Last VFO persisted across reboots Every QMX frequency change is saved to NVS using the existing debounced flush path (no flash churn - repeated 50 ms CAT polls of an unchanged dial are no-ops). On boot, the cached frequency is displayed immediately; CAT then corrects within ~50 ms if the QMX has moved.  The QMX remains the source of truth - the Tab5 only reads the saved value, never writes back to the QMX.  ### Build noise cleanup A stale forward declaration (`ui_set_db_labels_internal`) was removed, and two BSP unused-variable warnings (`gpio_if`, `gain` in the codec init path) silenced with `(void)` casts that survive future BSP resyncs cleanly.  ## Known issues  - Settings stored in the default `nvs` partition may be wiped by merged-binary reflashes (fixed in v0.9.4)  ## Flashing  Merged binary `qmx_panadapter-v0.8.2-merged.bin` attached below. Drop into [web.esphome.io](https://web.esphome.io/) from Chrome or Edge.  WiFi credentials and panadapter settings (dB range, EMA, IQ toggle) from a prior install are preserved in NVS.  ## Acknowledgements  Battery indicator polarity quirk and voltage curve details from [qrp_companion](https://groups.io/g/QRPLabs/topic/118645485) by Zhenxing Han (N6HAN), who documented that on the Tab5 INA226 the polarity is inverted vs the M5Unified docstring (negative shunt current = charging).
