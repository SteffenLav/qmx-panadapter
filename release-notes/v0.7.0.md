## Highlights  Three substantial additions: long-press screenshots, NVS-persisted settings, and blind adaptive I/Q balance correction.  ## What's new  ### Hidden long-press screenshot (Phase 5.11) - 1-second hold in the top-left 80x80 corner triggers a full-screen capture - Streamed as base64 over UART - Python decoder (`tools/screenshot_decode.py`) saves PNG to `~/Downloads`  ### I/Q balance correction (Phases A, B, C) - Gram-Schmidt blind adaptive image-rejection - Per-sample correction with running estimates of DC, amplitude ratio, and phase imbalance - Toggle in the settings drawer; default ON - Phase C tuned time constants for stability across operating modes  ### NVS settings persistence - dB range, EMA alpha, and I/Q enabled flag survive reboots - Debounced flush (500 ms after last change) minimises flash wear  ## Known issues  - Stale `ui_set_db_labels_internal` declaration warning (cosmetic, 2-line fix pending) - Settings are stored in the default `nvs` partition and may be wiped by merged-binary reflashes (fixed in v0.9.4)  ## Flashing  The attached `qmx_panadapter.bin` is a single-image binary, not a merged.bin. For a one-step web-flasher experience, use v0.6.1 or v0.8.0+ which ship a merged binary.
