## v0.11.1 — Top-bar quick-access control strip

Tap any label in the top bar to open a popup selector — no need to touch the QMX hardware.

### New features

- **Band popup.** Tap the Band label to open a dropdown of all bands configured in your QMX. The band list is read dynamically from the QMX at connect time via `MMBand config.` CAT commands, so it automatically matches your specific QMX variant (low/mid/top band). Selecting a band tunes the VFO to that band's configured center frequency. The current band is highlighted.

- **Mode popup.** Tap the Mode label to switch between USB, LSB, CW, and DiGi. Sends `MD;` CAT command immediately. Current mode highlighted.

- **BW popup.** Tap the BW label to select CW filter bandwidth (50/100/150/200/250/300/400/500 Hz). Sends `MMCW|CW passband=N;` to the QMX. Only opens in CW mode — SSB/DiGi bandwidth is not adjustable via CAT on the QMX.

- **Zoom popup.** Tap the Zoom label to select a zoom preset: ×1, ×2, ×4, ×8, ×16, ×24. Pan resets to centre on selection. Zoom persisted to NVS.

### Implementation notes

- Band list queried via `MMBand config.|Band name (m)[N];` and `MMBand config.|Frequency center[N];` at CDC-ACM open time. Stops on first empty/error slot.
- MM responses buffered in a dedicated `s_mm_resp` buffer (not the main `s_rx_buf`) to avoid race with the poll task resetting `s_rx_len` after each `;`.
- All popups use a full-screen transparent overlay to catch outside taps. Popup is centered under its label using `lv_obj_get_coords()` at open time.
- SSB bandwidth change via `MMSSB|Filter RX=N;` stores to EEPROM but does not apply to the live DSP chain without a power cycle — excluded from the UI for now.
