## v0.11.2 — ST7121 display compatibility fix

### Bug fix

- **Blank screen on Tab5 hardware revision post-April 2026.** M5Stack updated the Tab5 display controller from ST7123 to ST7121 in units shipped after approximately April 28, 2026. The merged binary now auto-detects which panel is fitted at boot time by reading the touch controller firmware version via I2C (FW=1 → ST7121, FW=3 → ST7123) and selects the correct driver and MIPI-DSI timing parameters automatically. No separate build is needed — one binary works on both hardware versions.

### Technical details

- Added `esp_lcd_st7121.c/.h` panel driver (from M5Stack UserDemo, Apache-2.0)
- ST7121 uses different vsync timings: pulse=20, back-porch=24, front-porch=200 (vs ST7123: 2/8/220)
- ST7121 uses a longer vendor init sequence and 1300 Mbps lane rate (vs ST7123: 965 Mbps)
- Detection and panel selection added to `bsp_detect_display_type()` and `bsp_display_lcd_init()`
- Touch input uses the same ST7123 touch driver for both panel variants (shared I2C interface)
